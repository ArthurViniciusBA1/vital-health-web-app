# **App Name**: VisitTrack Kiosk

## Core Features:

- Visitor Registration Form: Interactive full-screen registration form for visitor details.
- Input Validation: Data validation for required fields (Name, CPF, RG, Birth Date, Patient's Name).
- Submission Feedback: Display of success or error messages upon form submission.

## Style Guidelines:

- Primary color: Soft blue (#E8F5FF) for a calm and welcoming feel.
- Secondary color: Light gray (#F9FAFB) for backgrounds and neutral elements.
- Accent: Teal (#26A69A) for primary buttons and interactive elements.
- Full-screen, responsive layout optimized for kiosk mode with large, touch-friendly elements.
- Clear, legible text with sufficient contrast for easy readability on a screen.
- Simple, recognizable icons to aid navigation and form completion.

## Original User Request:
Quero criar um aplicativo de autoatendimento para um hospital, que será executado em um totem. A funcionalidade inicial é um formulário de cadastro de visitantes com os seguintes campos:

Nome

CPF

RG

Data de nascimento

Nome do paciente a ser visitado

O formulário deve salvar os dados em um banco de dados no Firebase (Firestore).

O aplicativo deve ter uma interface simples e amigável, com foco em experiência de usuário para tela cheia (modo kiosk).

O design deve ser responsivo e usar o Tailwind CSS para o layout.

Um botão 'Cadastrar' deve salvar os dados e exibir uma mensagem de sucesso ou erro após o cadastro.

O aplicativo deve ser otimizado para rodar em um totem de autoatendimento com uma interface limpa e intuitiva.
